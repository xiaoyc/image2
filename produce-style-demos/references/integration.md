# 接线与状态

## 已有与新增

已有：基础质量 Skill、各风格正文、单图 Preflight 编译入口、自然皮肤政策/检查，以及若干冻结批次。旧批次有景别设计和 QA，并不意味着此前已有独立且必须加载的 Demo Skill。

新增：本 `produce-style-demos` 入口、整组计划、冻结及逐图执行模板、style-brief 接口和离线校验器。它编排现有层，不替代风格分析或基底编译；不会生成图片或自动发布。本入口发布不等于安装为全局强制路由；调度新任务时需明确加载本 Skill。需要接入其他生产入口时，应显式链接本目录而非复制所有正文。

## 项目接线

- 基础/皮肤：当前已发布项目的 `base-image-production/SKILL.md`、`base-image-production/mandatory-constraints.json`、`skin_guard.py` 和 `prepare_image_request.py`。文件内容与真实版本绑定，不只写版本号。
- 单图编译：需要程序化设计时，可调用冻结的 Preflight 本地候选；否则允许手写并如实标 manual。新 Demo 不把已有手写桃霞案例改成 compiled。
- 风格：按目标选一个明确版本。唐风与琥珀仍在迭代，本入口不覆盖它们的文件；先核对当前正文/适用范围，再在计划中绑定实际文件。已接受奶杏/银灰/桃霞不能被候选风格替换。
- 参考图：已有 `style_reference` 适配器不等于已实现通用身份锁定。身份参考如使用，先实际看图、按图像工具真实参数准备显式文件，并运行基础皮肤检查。Demo 会运行随包基础皮肤检查器，并核来源角色和输入清单一致性，不证明身份保持或参考模式已图像实测。

## 景别判定

detail 为脸部局部、手/材质等真正细节，near 为头肩等近距离人物表达，medium 使人物动作或人与物关系可读，wide 使环境尺度和地点关系真正占有画面。范围按具体 brief 与原图解释，不用固定像素阈值替代审片。完整人形可仍是环境人像，不自动算远景；裁切已有图不能冒充新的原生景别样片。

## 拆图接口的边界

结构化 style-brief 让观察、推断与生成要求可追溯，但不是已实现一个独立图像拆解器。真实原图/完整公开描述是依据，用户反馈可修订规则，但旧输入和旧判断保留。拆解错误不能靠表单齐全掩盖，也不能把当前规则硬套到所有风格。

## 当前用户主角选择

Demo 主角固定年轻成年女性，气质、服装与动作按目标风格。配角不受一律女性限制；环境或局部辅助画面可不露主角。计划显式记录，校验器只验证声明，不能看图确认年龄或性别。此为用户当前项目选择，不是上游通用规则。
