# 银灰与原创风格参考：本地验证说明

2026-10-22。本地只运行Python标准库离线检查，没有调用图像模型、网络或付费API。发布前验证，不是GitHub CI结果。

- 44项unittest回归通过：原21项、银灰可移植记录10项、参考请求适配器13项。
- 基础0.3.3、原编译器和奶杏风格参数保持既有字节；银灰实际参数0.2.0。原六场景冻结39项摘要不变。
- 六份实际请求仍为纯文本，prompt可逐字节重编译；七规则人工映射行摘要可复核。Demo01–04历史提示词亦可回放，旧原图未纳入本次精选。
- 六张银灰原图及两张奶杏参考资产均通过PNG签名、块CRC、解压长度和扫描行检查；after与视觉证据绑定各自原图摘要。具体失败和用户整体接受分别保留。
- 两套参考manifest检查原创声明、角色、路径和SHA；请求实际输出referenced_image_paths，不将风格参考当身份锁。assembly id/版本/基础版本及prompt摘要不符会拒绝，输出文件已存在会拒绝覆盖。
- 默认纯文本没有图像引用字段，编辑/身份提示词不可被静默改解释为风格参考。历史actual request没有被参考适配器改写。

上述测试不证明视觉证据真实或审美通过。两套参考条件生成尚未图像实测，六张银灰不是参考模式成果；完整景别路由、视觉语义门禁、生成全链组合门禁和历史审美失败回归仍待实现。奶杏暂无原生特写参考。
