# 杏序花廊 · 柔金针织肖像

本条目是基础 Skill 的薄扩展，需与整套工程一起使用，未安装到个人 Skill 系统。实际编译参数的唯一维护源为 [apricot-colonnade.json](../apricot-colonnade.json)，不在本文件再复制一套规则。

先读取 [基础图像生产 Skill](../../base-image-production/SKILL.md)，再读取风格 JSON 的 fixed、overrides 与 override_reasons。奶白/柔桃杏/灰绿与温棕的主辅关系、暖发缘与柔亮脸并存、自然细腻材质和克制成人时装气质是本套特色。配色面积与相邻位置、光源方向和清晰度层次仍需服从实际画面设计，而非只出现几个颜色就算通过。

景别、人物大小、服装款式、场景、动作、表情、具体道具和位置放入本次输入，不逐套复制基础构图、物理、接触支撑或验收规则。民国、古典等其他风格应另建自己的参数，不把本套暖色规则带过去。

冲突处理：先保留基础的物理/自然比例/证据规则，再应用明确声明的美术覆盖。风格只可覆盖允许的美术参数；输入若与固定风格相冲突，先解决冲突，不静默丢弃。前检、编译、实际原图后检与用户验收仍走基础流程；本文件不授予生图数量或发布权限。

公开参考为 [奶杏暖庭·柔光时装人像](https://gonghaosnail.com/skill-library)。它只用于理解描述和视觉规律，不是我们的作品，不进入生成图像输入。固定与可变边界及许可证见 [来源说明](../../SOURCES-AND-LICENSE.md)，扩展另一套风格时使用 [扩展模板](../../references/style-extension-template.md)。

本次环境叙事维护在JSON的style_features，具体物件及方位仅见[004-r3编辑输入](../../inputs/series-004-r3.json)。人物仍是主，远处生活层不是另一张同等重要的群像。

## 004-r3动作输入修订
本套温和生活气息不能只靠环境配角，主角动作也须有明确目的和阶段：看手与物的抓握/移动、肩颈与重心是否随同一行动变化。不要用刻意微笑、侧倾、伸直手臂和展示衣摆的组合代替自然。此条应用既有style_features的自然、不僵硬要求；不改变配色、光线、材料和相机参数。r3只改具体动作输入，不把某种取书姿势变成固定风格。
