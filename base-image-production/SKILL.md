# 基础图像生产 Skill v0.3.3

这是项目内可阅读、可离线组装的 Skill 源文件，未自动安装到个人 Skill 系统。沿用基础加风格的两层结构，不引入复杂框架。

## 责任边界

- [base.json](base.json) 只维护通用方法：注意力层级、大中小和疏密节奏、视觉路径、主体与动作及辅助物的关系、光线、材质、物理、解剖、可见眼睛与审片方法。不得写入某个地点、建筑、服装或固定色彩。
- 风格 JSON 定义色彩、光质、材质倾向、镜头气质和氛围，可明确覆盖媒介等美术默认项。景别、机位、人物大小、具体道具、位置和动作不是固定风格参数。
- 本次输入定义人物、服装、动作、神情与视线、三层环境和构图，可指定比例。三层是空间描述，不要求层层堆物；某层无额外元素时如实说明。

字段契约及三个模式见 [style-extension-template.md](../references/style-extension-template.md)。不把示例风格或旧画面自动当作本次决定。

## 选择模式

1. generate：没有图像输入，从本次文字生成单张原创画面。
2. edit：唯一输入是我方原创编辑目标。明确 preserve 与 change，按本次输入保留或修改旧画面。
3. identity_reference：唯一输入是我方已生成的原创人物图，只承继人物身份、脸、头发、肤色和身体比例；明确释放旧构图、景别、机位、场景、衣服、道具、动作与光线布置，创作一张新画面。它不是旧画面编辑，也不是无参考纯文本测试。

参考模式不得混用。竞品图仅可在另行授权的研究对照中查看，不能进入本项目生成或编辑输入。源图元数据须声明我方原创来源并记录完整 SHA256；字节校验能证明文件一致，不能独立证明作者或版权。

## 执行

读取基础、风格和本次输入，核对版本。有人像时明确成年年龄；确定本帧的原生景别、主动作、辅助落点与连接机制，让支撑和受力可读。静物等任务不强行添加人物动作。

先依据 [九项前后检查](../references/review-methods.md) 完成 before 记录，绑定本次输入的文件与 SHA256。每项必须写具体设计证据和 pass、fail 或 not_applicable；不适用也须说明原因，无法确认记 fail。任一 fail 先改设计，禁止继续生成。

调用项目根目录 compose_prompt.py，必须提供 --review 指向该 before 记录。脚本验证九项完整性、声明状态、目标文件和摘要，不联网、不生图、不读取 API key；声明 pass 不是脚本给出的审美结论。风格不得替换基础质量规则，输入不得暗中覆盖固定风格。

人工读完整 assembled-prompt.txt：输入与风格是否相容？身份继承是否误锁衣服或取景？大中小元素是否有节奏？留白是否承接情绪、视线或动作？辅助物是否真的参与画面而不是填空？

只在用户授权的数量与范围内调用正式图像工具。实际调用前保留当时的完整提示词、参数及参考图路径；actual-prompt.txt、tool-request.json、generation-record.json 只能记录真的发送或返回的内容，不能把编译产物提前改名成实际运行记录。

系列按用户要求逐张完成、逐张交付。每次工具返回后必须独立查看未裁切原图并填写 after 记录，绑定实际图片的文件和 SHA256，不复制 before 的通过结论。任一 fail 即整体未通过；用户要求看图时仍及时交付并明确失败项，不能自动重试。

下一张沿用冻结的基础和风格，场景差异落在输入中；后续若修改规则或重试，分别记录版本、调用和原因，不回填或覆盖已经执行的历史。001/002 的实际 0.3.0 执行记录由原始工程留档，当前发布不冒充旧图的原始来源。

## 审片

依照 base.json 的 review_methods 看实际图，不把提示词意图当成已生成事实。先看小图的第一焦点、尺度疏密和观看路线，再放大核对光向、接触支撑、材料、解剖与眼神。对没有看清的必要结构写具体原因并记 fail，不以 not_applicable 或模糊的“保留项”掩盖未通过。

基础质量、风格表现和人物身份分别检查。景别以真实截幅、人物相对尺度、环境占比为准，不以文字标签代替；不裁切放大旧图冒充新的原生特写，也不拿不同景别当作严格同条件风格验证。

分别记录：文本组装通过、图像工具返回、实际看图检查、用户确认。四份输入或四次成功调用都不能自动证明系列稳定或用户满意。优先解决最影响结果的一项，并定位问题属于基础、风格或本次输入。

来源及复用边界见 [SOURCES-AND-LICENSE.md](../SOURCES-AND-LICENSE.md)。

## 本轮强化的显式验收门槛

见 [review-gates.md](../review-gates.md) 和 [九项前后检查](../references/review-methods.md)。先按邻近、相似与实际连接合并重量组，再判断居中、不对称或有意偏置；贴身道具不能重复算作独立配重。留白要有语境，不强制另一侧添加物件。没有明显解剖畸形也要检查肩、腰、髋、膝转折、自然臂展和座面支撑是否可读。

方法采用对 Photo Edit Analysis 和 Photo Composition Critic 的独立转述及项目补充，不复制全文、脚本或固定评分算法。来源、许可证与哪些内容属于项目新增，见九项检查和来源文件。结构校验只验证记录完整性和声明状态，不能自动评美、证明证据真实或代替用户验收。

## 环境叙事与审查校准
先读[校准补记](../review-addendum-20261022/CALIBRATION.md)。面积大、出画、合理背景人物不是自动失败；透明度与内容兴趣须纳入重量判断。基础只检查主次/空间用途/生活层是否可读而不抢戏，不能规定盆栽、桌椅、饮茶是所有图片必备。有关证据写入negative_space与viewing_connections，不增设自动审美分数。

如任务追求自然生活动作，生成前必须读取[人物自然度](../references/pose-naturalness.md)：先定义目的和动作阶段，再核对抓握/受力、身体支撑、视线和肩颈放松是否属于同一行动；将设计证据写入before的pose_and_support、viewing_connections、proportions_and_position。生成后重新看实际像素，分别记录物理成立、动作可读与自然程度，不把没畸形或有道具当自然度通过。空闲手不必强加动作。具体取册/翻页/扶门等仅在本次输入，不能变成所有风格必备。

此可复用规则由004-r2反馈开始形成，004-r3实际采用了动作阶段与抓握/屈肘/重心的输入检查。r3后本段扩写执行入口与模板，未改旧调用记录；更详细文档的发布时间不冒充已运行编译器的新功能。

## 0.3.3 运行规则固化
自然度六问现已同时进入base.json的anatomy、physics与pose_and_support，编译器每次会读取并拼入通用提示词，不只保留在说明文档。风格JSON保留亲近克制、自然非展示的特色；具体取册动作仍只在input。0.3.3本地编译与结构回归已经纳入测试，尚未独立生成新图；r3真实调用使用0.3.2参数快照，不能混淆版本。
