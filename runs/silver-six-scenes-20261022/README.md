# 银灰短发六场景测试（2026-10-22）

本套风格已获用户整体接受。六张均为首次纯文本原创生成，无竞品或我方整图参考、无重试/选优/修图；人物只有共同选角描述，没有身份锁。六个输入、意图卡、规则映射和实际prompt在首次生成前冻结。各张分别输出，16:9意图，原图为1672×940或1672×941（原生近似比例），未裁切成新图。

基础/编译器0.3.3沿用已发布版本；银灰风格0.2.0不改。近景、中景、全身各两张。第1张完成后，2/3/4并发，5/6随后并发；每场景只调用一次。6张探索样本不证明统计稳定或任意场景都适用。

## 结果与验收层次

- 图像工具执行：6张均返回原图。
- 视觉审查：实际逐张看原图，分构图、风格、输入遵循、物理/自然度。具体证据见 reviews。
- 用户验收：接受银灰Skill整体效果并授权公开发布；未把具体偏差改写成符合。
- 严格参数：全部图仍有微小RGB通道余差，未达字面上的完全无彩；03开书而非合拢，03/05人物占比更大，04杯离托更高，05步态阶段未完全确认，06轻启唇而非轻合。
- 九项后检的fail包含严格参数/未确认事项，不等于照片审美失败或用户拒绝。本轮不自动返工。

## 实际内化程度

已实现：通用构图/光线/材质/物理与自然动作规则进入基础；独立银灰光色材质及选角字段进入最终prompt；已有9项前后检记录校验；本轮人工建立每帧意图卡、7条规则到prompt行的映射、原图hash及实际视觉证据。

尚未实现：基于景别自动选择适用规则；规则证据的语义真实性门禁；input/base/style/compiler/actual prompt/image/review全链组合版本自动门禁；覆盖历史审美误判的完整失败回归。当前文档、hash和标准库测试不能代替这几项，也不能自动证明画面好看。

当前六张是 text-only 测试。后续附加我方原创风格参考资产的配置/请求接线与 reference-conditioned 图像实测是不同事项；本轮没有参考图模式生成，不能将此批图列作该模式验证。

- inputs：冻结的6个输入、每帧意图卡和规则映射。
